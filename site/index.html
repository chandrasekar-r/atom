New in v0.3.0

  • Long-term memory that lasts across sessions. Cloudflare's clef-flash classifier decides what is worth remembering and when to recall it, and bge-m3 embeddings store the facts locally. D1 sync through the gateway is optional. Manage it with /memory.
  • Web search with no key (DuckDuckGo, falling back to Bing RSS). The router nudges the model toward it when a question needs current information.
  • MCP over stdio, Streamable HTTP and SSE. Add a server with atom mcp add NAME --url ….
  • Plugins (local or npm): add tools, slash commands, event hooks, and bundled skills or commands
  • Skills: SKILL.md folders are auto-discovered from .atom and .agents. The model loads one when it's relevant, and you can also run it as /skill.
  • Repo index: atom index plus a semantic_search tool. Embeddings use bge-m3, the index respects .gitignore, and updates are incremental. There is also a repo_map tool.
  • @ mentions for folders, globs, line ranges @file:10-40, symbols @#name and images
  • Projects: atom project add/list/switch and atom -P. Each project has its own instructions, knowledge files, settings, memory and sessions.
  • Custom subagents in .atom/agents, and an arrow-key /model picker
  • atom update, plus a daily background check shown in the footer. Set autoUpdate to install automatically.

What's in it

  • Differential TUI: streaming Markdown, a spinner with elapsed time and token count, and Esc to interrupt
  • Shift+Tab cycles the ask, accept-edits, plan and bypass modes. Permission dialogs show coloured diffs.
  • Slash-command menu with autocomplete, @ fuzzy file mentions (the file is inlined), multiline input (\⏎ or Alt+⏎), and persistent history
  • Inline todo list, a task subagent tool, automatic /compact near the context limit, and visible thinking (Ctrl+T)
  • Session tree: /tree or Esc Esc lets you branch from any earlier message, and /fork copies the chat into a new session
  • Loads AGENTS.md and ATOM.md. Lines starting with # are saved to memory.
  • Image input: Ctrl+V pastes from the clipboard, and you can also paste or @ a .png path (use with llama-4-scout)
  • Kept from v0.1: file checkpoints with /rewind, -p print/JSON mode, MCP (stdio), hooks, custom commands, /resume, and /cost

Install: bring your own Cloudflare account

$ npm i -g @rclabs/atom   # Node 22+
$ atom login                         # opens a pre-filled "Workers AI Read + Edit" token page; paste the token
$ atom                               # start in your project

Package: @rclabs/atom on npm. You can also log in with your own browser session through atom login --wrangler.

  1. Create a free Cloudflare account at dash.cloudflare.com. The Workers AI free tier includes 10,000 neurons a day.
  2. Run atom login. Atom detects your account ID and checks that the token really can run Workers AI before it saves anything to ~/.config/atom/credentials.json (mode 0600).
  3. Everything runs in your account, and Atom has no server of its own. Keep it up to date with atom update.
